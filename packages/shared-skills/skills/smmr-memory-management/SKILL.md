# Memory management

Separate memory into:

- episodic: what happened in this task;
- semantic: reusable facts about code, tools, or APIs;
- procedural: verified workflows and skills.

Reading memory is not proof. Before writing, require a specific reusable claim,
supporting evidence, non-contradiction with current knowledge, and permission
for durable writes. Prefer bounded, deduplicated entries with provenance and a
confidence value. Never store secrets, credentials, or unverified guesses.
