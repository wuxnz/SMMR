# Research first

1. State the concrete unknown and why repository evidence is insufficient.
2. Prefer primary documentation, source code, specifications, and reproducible
   examples. Use only the minimum network access permitted by configuration.
3. Record source URL or file, relevant claim, retrieval time, and confidence.
4. Stop when the research budget is exhausted or the unknown is resolved.

Never present an uncited external claim as verified repository knowledge.
